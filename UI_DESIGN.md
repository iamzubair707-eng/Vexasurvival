# Pro UI Design Guidelines

## Buttons
- **Normal**: Dark gray `#2d2d44`, rounded corners (10px), subtle shadow
- **Hover**: Neon blue `#0f3460` + glow effect
- **Press**: Scale down 0.95 + darken color
- **Disabled**: Gray `#555`, opacity 0.5

## Panels
- Background: Semi-transparent black `rgba(0,0,0,0.85)`
- Border: 2px, neon blue `#0f3460`
- Corner radius: 15px

## Progress Bars
- Health bar: Red gradient
- XP bar: Blue gradient
- Shield bar: Green gradient
- Add: Smooth fill animation (0.2s)

## Fonts
- Title: Bebas Neue / Impact (bold, large)
- Body: Roboto / Arial (clean, readable)
- Numbers: Monospace (for resources/VEXA)

## Animations
- Button click: Scale 0.95 → 1.0 (0.1s)
- Reward popup: Bounce effect
- Damage flash: Red overlay 0.2s
- Level up: Particle burst + screen shake
