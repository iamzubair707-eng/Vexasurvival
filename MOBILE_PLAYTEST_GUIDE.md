# 📱 VEXA SURVIVAL - Mobile Playtest Guide

## Build APK
1. Unity → File → Build Settings
2. Platform: Android
3. Build → Save as "VexaSurvival_v1.0.apk"

## Test Checklist (Daily)

### Core Loop Test
- [ ] Gather resources → wood/stone increase
- [ ] Upgrade building → level increases, cost updates
- [ ] Train troops → troop count increases
- [ ] Start raid → victory/defeat with rewards
- [ ] Open chest → random rewards

### Performance Test
- [ ] FPS stable (30-60 on mid-range)
- [ ] No lag on button clicks
- [ ] Smooth movement
- [ ] Fast UI transitions

### Mental Health Test
- [ ] Do 5+ raids → mental health drops
- [ ] Watch state change (Stable → Stressed → Depressed)
- [ ] Effects apply (production down, rebellion)
- [ ] Build counseling center → heal

### Offline Test
- [ ] Close game → wait 10 min → reopen
- [ ] Check offline rewards notification
- [ ] Resources should have increased

### Save/Load Test
- [ ] Play 5 minutes
- [ ] Close and reopen game
- [ ] Progress should be saved

### Crash Test
- [ ] 15 minutes continuous play
- [ ] Rapid button clicking
- [ ] Open all menus repeatedly
- [ ] No crashes
